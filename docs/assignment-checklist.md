# 제출 전에 확인할 것

기준은 [교수님 과제 안내](https://actually-war-1ea.notion.site/AI-1cf7f4c86693800e9e11fa490ed1a2ff)입니다.
아래는 팀이 확인하기 쉽게 줄인 목록입니다. 예제 실행만으로 완료 표시하지 않습니다.

## 반드시 지킬 조건

- [ ] 분야: 농업 / 에너지 / 의료 AI / Physical AI·로봇 / 반도체 중 선택.
- [ ] 기업: 비상장, Seed~Series C 수준, M&A 등 Exit 미완료를 자료로 확인.
- [ ] LangGraph로 여러 역할을 연결하고 실제 AI 분석을 구현.
- [ ] 탐색·기술 요약·시장 평가 중 최소 한 역할에 **실제 RAG** 적용.
- [ ] RAG 문서는 개수와 관계없이 **전체 200쪽 이하**. 자료별 페이지 수 기록.
- [ ] **오픈소스 임베딩** 사용. 후보 비교와 선택 이유 기록. 순위만으로 선정하지 않기.
- [ ] Agentic RAG: 검색 도구 호출·검색 결과 확인 등 판단에 따른 실행을 구현.
- [ ] 투자 판단이 보류이면 다음 후보로 이동. 모든 후보가 보류이면 종료 후 보고서 작성.
- [ ] 실제 보고서 생성, 실행 방법, 사용한 모델·패키지·검색 평가 결과 기록.

## 필수 조건과 팀의 선택 구분

- 평가 가중치 30/25/15/10/10/10은 안내의 **참고안**입니다. 팀이 이유를 정리해 조정할 수 있습니다.
- 70점 기준, 재검색 최대 1회, FAISS 선택은 **팀의 초안**이며 교수님의 고정 조건이 아닙니다.
- Self-RAG·Corrective RAG·Adaptive RAG·GraphRAG·이미지 생성·Ragas를 전부 구현할 필요는 없습니다.
- 회사와 도메인은 미정이며, 선정 후 자료와 기준을 바꿀 수 있습니다.
- API 키와 수업 원본·재배포 권한이 없는 자료는 공개 저장소에 올리지 않습니다.
