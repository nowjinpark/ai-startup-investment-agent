# AI 스타트업 투자평가 — 과제 요건 및 제출 점검표

이 저장소는 대상 기업을 바꾸어 사용할 수 있는 AI 스타트업 투자평가 에이전트를 5명이 함께 만드는 **협업용 시작 코드와 계획 문서**입니다. 현재 데모는 두 가상 후보로 연결 흐름을 보여주며, 실제 기업 분석이나 과제 제출 완료를 뜻하지 않습니다. 아래 체크박스는 실제 실행과 산출물을 확인한 뒤에만 표시합니다. 수업 과제의 요구사항을 작업과 검증 항목으로 요약했으며, 수업 원문을 전재하지 않습니다.

## 대상 기업과 데이터

- [ ] 과제가 허용한 5개 도메인 중 팀의 분석 도메인을 선택하고, 대상 기업이 해당 AI 스타트업 범위에 들어가는 근거를 확인했다.
- [ ] 도메인·대상 기업·분석 기준일·후보 목록을 `config/project.json`에서 설정했다. 가상 데모 후보를 실제 분석 대상으로 오인하지 않는다.
- [ ] 공개자료의 확인일을 기록하고 비상장, Seed~Series C 범위, 인수·상장 등 Exit 여부를 검토했다. 확인되지 않은 사항을 확정 사실로 쓰지 않는다.
- [ ] 분석 기준일을 고정하고, 투자 완료·도입 완료·PoC·협약·계획을 구분했다.
- [ ] RAG에 사용할 **공개자료 총량을 200쪽 이하**로 제한했다. 모든 후보와 재실행·재검색으로 추가한 자료를 전체 목록에서 함께 집계하고, 실행마다 한도를 새로 부여하지 않는다.
- [ ] 웹 자료도 보존한 문서의 페이지 수로 관리하는 등 팀의 산정 방식을 합의하고 적용했다. 불명확한 산정 규칙은 과제 안내와 대조했다.
- [ ] 각 자료의 제목, 발행 주체, 원문 URL, 발행일 또는 기준일, 사용 범위와 페이지 수를 기록했다.
- [ ] 공개 열람 가능 여부와 GitHub 재배포 가능 여부를 별도로 확인했다. 권한이 불명확한 원문은 저장소에 올리지 않고 출처와 준비 방법을 제공한다.
- [ ] 비밀키·개인정보·비공개 IR·수업 원문·재배포 권한이 없는 PDF가 공개 저장소에 포함되지 않았다.

## 시스템 필수 구현

- [ ] LangGraph를 사용한 멀티에이전트 흐름을 실제로 구현했다.
- [ ] 분석 역할과 각 에이전트의 책임·입출력·사용 도구를 구분했다.
- [ ] 최소 **1개 이상의 RAG**가 실제 문서 검색과 답변 근거 제공에 사용된다.
- [ ] **오픈 임베딩 모델**의 선택 이유, 모델명·버전, 실행 환경을 기록했다.
- [ ] 문서 전처리 → 분할 → 임베딩 → 저장 → 검색 → 근거 전달이 연결된다.
- [ ] 판단에 따라 검색 또는 실행 경로가 달라지는 Agentic RAG 동작을 검증했다.
- [ ] 근거 부족 시 **최대 1회 재검색**하고, 이후에도 부족하면 보류와 정보 공백을 보고하도록 구현했다. 이는 팀의 구현 계획이며 시작 코드의 완성 기능을 뜻하지 않는다.
- [ ] 첫 후보 보류 후 **다른 후보를 실제로 평가하는 분기**를 검증했다. 단일 후보 종료만으로 후보 전환 요구를 충족했다고 표시하지 않는다.
- [ ] 다음 후보 없음, 모든 후보 보류 등 종료 경로가 무한 반복 없이 끝난다.
- [ ] 공통 상태와 입출력 계약은 `contracts/schema.py`와 일치한다.
- [ ] 모의 입력으로 연결만 확인한 결과와 실제 모델·검색을 사용한 결과를 구분한다.

## 보고서 내용 확인

- [ ] 첫 SUMMARY가 0.5쪽 이하이며, 판단·핵심 근거·주요 미확인을 짧게 설명한다.
- [ ] 사업 아이디어와 해결하는 고객 문제를 설명한다.
- [ ] 시장 규모의 정의·자료 기준일·출처와 추정의 한계를 표시한다.
- [ ] 팀과 기술·제품, 경쟁력, 사업 실적, 투자 관련 확인 사항을 평가한다.
- [ ] 시장·기술·규제·경쟁 리스크를 각각 다룬다.
- [ ] 미확인 정보와 분석·시스템의 한계를 명시한다.
- [ ] 끝의 REFERENCE에는 **보고서에서 실제 인용한 자료만** 넣는다.
- [ ] SUMMARY와 REFERENCE를 포함해 보수적으로 전체 5쪽 이하로 맞추고, 별도 표지를 추가해 초과하지 않는다.
- [ ] 숫자·고객명·도입 범위·시점과 출처를 대조했다. 자료 부족을 매출 0 또는 실적 없음으로 단정하지 않는다.
