[최종 결과와 입력](../examples/final/)의 `records.json`은 보고서에 필요한 인용 부분만 포함합니다. 전체 원문·준비 후보는 팀 공유 자료에 있습니다. `report`는 저장 결과를 그대로 문서화하므로 새로운 기업 검색·점수 변경·API 호출이 없습니다.

## 실행 검증

- 자동 검사: **278개 통과·선택 네트워크 검사 1개 생략·하위 검사 4개 통과**입니다.
- 전체 연결: 가상 기업 6개 평가 후 후보 5개 확보, 모두 보류일 때 7개 평가 후 종료를 확인했습니다.
- 제출 PDF: **5쪽**, 한글 본문 9.5pt입니다. 공개 저장 결과로 API 없이 재생성했습니다.
- 실제 BGE-M3 검색: 질문 15개, **Hit Rate@4 1.0 / MRR@4 0.956**입니다. Codex가 만든 원문 기반 회귀 질문이며 팀의 독립 평가나 답변 정확도 100%를 뜻하지 않습니다.
- 의존성 검사에 충돌이 없었습니다. 이번 원문 교정·재채점·보고서 검증의 추가 API 호출은 0회입니다.
- 새 구조화 검수 방식은 자동 검사로 확인했으며, 변경 후 유료 API 전체 실행은 다시 하지 않았습니다. 라이브 결과는 달라질 수 있습니다.

## 검색 검증 범위

`data/evaluation.final.json`의 15개 질문을 최종 164쪽 문서에서 검색했습니다. 실제 로컬 BGE-M3 임베딩과 FAISS 상위 4개 결과를 사용했습니다. 회사별 질문은 기업 범위를 제한하고, 공통 시장·경쟁 질문은 산업 자료를 사용했습니다.

Hit Rate@4는 지정 정답 페이지가 상위 네 결과에 들어온 비율이며, MRR@4는 정답이 얼마나 앞에 나왔는지를 나타냅니다. 이번 값은 각각 1.0과 0.95556입니다. Codex가 구성한 작은 회귀 질문 집합이며 일부 제외 기업도 검색 확인에 포함되어 있습니다. 독립 평가셋이나 투자 판단·답변 전체의 정확도로 해석하지 않습니다.

## 실행 환경과 한계

macOS·Python 3.11, 로컬 BGE-M3, LangGraph 1.0.9, FAISS 1.13.2를 사용했습니다. 직접 의존성은 `requirements.txt`, 간접 의존성 기록은 `requirements-lock.txt`에 있습니다. 새 GPT 구조화 검수는 모의 응답 검사까지 확인했으며 실제 API로 재실행하지 않았습니다. 원문 인용의 문자열 일치가 의미상 충분한 근거임을 보증하지는 않습니다.

국내 세부시장의 TAM·SAM 금액을 확인하지 못한 기업은 넓은 업계 통계의 연도·범위를 함께 표시했습니다. 경쟁사 공식 제품 설명의 비교이며 독립 실측 성능 비교가 아닙니다. KIPRIS·ScienceON·나라장터 등의 전용 API는 연결하지 않았습니다. 확인하지 못한 기업 자격은 조건부 후보의 확인 항목으로 남겼습니다.
