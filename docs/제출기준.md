## 설계 변경

팀이 조사하기 어려웠던 기존 1·4·5·9번을 점수에서 제외하고, 기존 2·3·6·7·8·10번 여섯 항목으로 변경했습니다. **18점 만점, 12점 이상**은 평균 중 수준입니다. 여섯 항목의 근거가 모두 있을 때만 총점을 계산하며, 미확인 값을 임의로 채우지 않습니다.

점수와 기업 자격을 구분합니다. 자격까지 확인되면 추천, 12점 이상이지만 자격 확인이 필요하면 조건부 후보로 표시합니다. 확정 부적격이나 근거 있는 중대한 미해결 위험은 보류합니다. 추천·조건부 후보를 합쳐 5개 확보하거나 목록을 소진하면 보고서를 만듭니다.

제외한 네 항목은 보고서에서 필요한 기술·팀·시장·위험 설명에 남깁니다. [평가기준](평가기준.md), 코드 설정, README, 보고서에 같은 버전 3.0을 사용합니다. 자료가 없거나 모두 보류인 결과도 이유를 밝혀 제출하며, 후보 수나 검색 성능을 꾸미지 않습니다.
