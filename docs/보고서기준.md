# 투자 보고서 기준

`agents/report.py`는 저장된 투자 판단을 PDF와 상세 Markdown으로 정리합니다. 추가 API를 호출하지 않으며 점수와 추천·조건부·보류 판정을 바꾸지 않습니다.

## 구성

1. **SUMMARY**: 첫 반쪽 이내에 평가 범위, 추천과 조건부 후보의 구분, 핵심 근거, 추가 확인 사항을 요약합니다. 탐색 중 제외된 기업은 실제 평가한 기업 수와 구분합니다.
2. **기업 비교**: 추천·조건부 후보를 합쳐 최대 5개까지 18점 기준 점수 내림차순으로 표시합니다. 조건부 후보에는 미확인 자격을 명시합니다.
3. **평가표**: 여섯 항목의 상·중·하·미확인과 확인 항목 수를 표시합니다. 하나라도 미확인이면 총점은 미확정입니다.
4. **기업별 분석**: 사업 아이디어, 기술·팀, 시장·고객, 시장 규모, 경쟁 비교, 위험·한계를 설명합니다. 점수에서 제외한 시장 성장성·기술 차별성·팀 전문성·위험도 필요한 본문 설명에 남깁니다.
5. **REFERENCE**: 본문에 사용한 출처의 기관, 발행일, 제목, 원문 페이지, 수집일, 전체 URL을 표시합니다. 확인하지 못한 발행일은 추정하지 않습니다.

## 판단 표시

- 점수 충족: 여섯 항목의 근거 확인 후 합계 **12/18점 이상**
- 추천: 점수 충족 및 기업 자격 확인 완료
- 조건부 후보: 점수 충족, 일부 자격의 추가 확인 필요
- 보류: 점수 미달, 근거 부족, 확정 부적격, 분석 실패 또는 근거 있는 중대한 미해결 위험

총점과 자격을 별도로 표시해 ‘높은 점수’가 곧 ‘모든 조건 확인’으로 읽히지 않게 합니다. 미확인 항목에 0점이나 중 등급을 넣지 않습니다.

모두 보류이면 기업별 사유와 부족한 근거를 정리합니다. 총점이 확인된 기업에 한해서 기준선에 가까운 기업을 비교합니다. 전부 총점 미확정이면 확인 항목 수에 따른 **추가 확인 우선 기업**으로 설명하며 투자 순위를 붙이지 않습니다. 시장 시사점은 이번 평가 표본으로 범위를 한정합니다.

## 근거와 분량

원문 인용과 기업 식별을 확인하고, 검증되지 않은 요약을 사실로 옮기지 않습니다. 기업 매출을 시장 규모로 바꾸지 않으며, 자료가 부족한 기술·팀·경쟁 정보는 확인 필요로 남깁니다.

PDF는 **REFERENCE 포함 5쪽 이내**, 흑백·한국어 존댓말로 작성합니다. 본문과 출처는 최소 8.5pt를 유지합니다. 중복 설명을 먼저 줄이고, 상세 분석과 나머지 기업의 보류 표를 나눠 배치합니다. 보류 사유와 URL을 생략 부호로 자르지 않습니다.

PDF에 표시한 분석의 출처를 싣고, 상세 Markdown에는 전체 평가 근거를 보존합니다. 두 파일의 출처 번호는 동일합니다. 핵심 내용과 출처를 유지하면서 5쪽을 충족하지 못하면 오류로 알리고 Markdown을 보존합니다.

## 검증

```bash
./.venv/bin/python -m pytest -q tests/test_report.py
```

추천·조건부·전원 보류, 근거 미확인, 인용 검증, 긴 URL, PDF 분량, API 미호출을 검증합니다. 최종 PDF의 줄바꿈과 표 잘림은 페이지를 열어 별도로 확인합니다.
