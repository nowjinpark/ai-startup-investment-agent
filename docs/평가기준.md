# 투자 평가 기준 3.0

국내 비상장 Seed~Series C Physical AI 기업을 공개 자료로 비교합니다. 팀 논의에 따라 찾기 어려웠던 기존 **1. 시장 성장성, 4. 기술 차별성, 5. 팀 전문성, 9. 위험 관리**를 점수 항목에서 제외했습니다. 이 내용은 근거가 있을 때 보고서의 기술·팀·시장·위험 설명에 남깁니다.

## 평가표

기존 2·3·6·7·8·10번을 아래 여섯 항목으로 표시합니다. 코드의 기존 ID는 저장 자료와 연결하기 위해 유지합니다.

| 표시 번호 · 기존 ID | 항목 | 상 · 3점 | 중 · 2점 | 하 · 1점 |
|---|---|---|---|---|
| 1 · 2 | 문제 해결 효과 | 고객 현장의 개선 효과 검증 | 고객 환경 PoC·실증 | 자체 실험실·데모 단계 확인 |
| 2 · 3 | 고객 구매 의사 | 유료 계약·유료 PoC | 무료 PoC·LOI·MOU·구체적 도입 협의 | 고객 접점이 없다는 명시적 근거 |
| 3 · 6 | 외부 고객·현장 검증 | 실제 검증 고객·현장 2개 이상 | 1개 | 0개라는 명시적 근거 |
| 4 · 7 | 수익모델 명확성 | 과금 구성 요소 4개 확인 | 2~3개 확인 | 0~1개 확인 |
| 5 · 8 | 적용 분야 확장 | 검증된 산업·사용 목적 2개 이상 | 1개 | 0개라는 명시적 근거 |
| 6 · 10 | 실행 지속성 | 현재 활동과 날짜가 다른 완료 성과 2개 이상 | 최근 실제 사업 활동 | 공식 폐업·관련 사업 중단 확인 |

과금 구성 요소는 **지불 주체, 판매 제품·서비스, 과금 단위, 가격 산정 방식**입니다. 공개 가격 자체는 필수가 아닙니다. 같은 사건의 재인용 기사는 중복 계산하지 않으며, 미래 계획을 완료 실적으로 세지 않습니다. 고객 수와 적용 분야 수를 구분합니다.

자료가 없으면 **미확인(`null`)**입니다. 검색되지 않았다는 이유로 0건 또는 하 등급을 주지 않습니다. 유료 여부가 확인되지 않은 MOU를 유료 계약으로 해석하지 않습니다.

## 점수 기준

**여섯 항목을 모두 확인한 뒤 합계 12점 이상이면 점수 기준을 충족합니다.** 최대 18점이며, 여섯 항목이 모두 중이면 `2점 × 6개 = 12점`입니다. 초기 기업의 실증·고객 접점·사업 구조를 검토 후보로 인정하기 위해 평균 중 수준으로 정했습니다. 기존 24/30점의 평균 2.4점에서 평균 2점으로 완화한 팀의 과제용 기준입니다.

| 평가 결과 | 점수 처리 |
|---|---|
| 여섯 항목 확인, 합계 12점 이상 | 점수 기준 충족 |
| 여섯 항목 확인, 합계 11점 이하 | 점수 미달로 보류 |
| 하나라도 미확인 | 총점 미확정, 추가 근거 확인을 위해 보류 |

미확인 값을 평균이나 0점으로 채우지 않으며, 18점으로 환산하지 않습니다. 확인된 점수 합계(`observed_sum`)는 진단용으로 보관하고 완성된 총점과 구분합니다.

## 기업 자격과 최종 분류

국내·비상장·Seed~Series C·Exit 미완료·Physical AI 조건, 법인 동일성, 현재 사업 운영을 점수와 별도로 확인합니다.

| 분류 | 조건 |
|---|---|
| 추천 · `pass` | 12점 이상이며 기업 자격 확인 완료 |
| 조건부 후보 · `conditional` | 12점 이상이지만 일부 기업 자격의 추가 확인 필요 |
| 보류 · `hold` | 점수 미달·평가 근거 부족·확정된 부적격·분석 실패·근거가 확인된 중대한 미해결 위험 |

조건부 후보를 자격 확인이 끝난 추천 기업으로 표시하지 않습니다. 예를 들어 비상장 여부가 미확인이면 확인할 조건을 보고서에 적습니다. 상장 사실이나 Exit 완료가 확인된 기업은 높은 점수를 얻어도 보류합니다.

위험 정보를 찾지 못했다는 이유만으로 자동 보류하지 않으며, 위험이 없다고 단정하지도 않습니다. 확인된 위험과 추가 검증 사항은 본문에 남기고, **근거가 있는 중대한 미해결 위험**은 별도 보류 사유로 처리합니다.

추천·조건부 후보를 합쳐 5개 확보하거나 준비한 목록이 끝나면 분석을 종료합니다. 확보한 후보를 총점 내림차순으로 정리하며, 아직 평가하지 않은 기업까지 포함한 전체 최상위 5개라는 뜻은 아닙니다.

## 재채점

버전 3.0은 기존 자료에서 남은 여섯 항목의 사실과 출처를 가져와 다시 계산합니다. `regrade`는 원래 기록을 보존하고 변경 내역을 남기며 API를 호출하지 않습니다. 확인되지 않은 근거를 새로 만들지 않습니다. `report`는 저장된 점수를 그대로 문서화하므로, 기준 변경에는 재채점을 먼저 사용합니다.
