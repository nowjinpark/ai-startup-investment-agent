# 팀 역할과 이번 제출물의 연결

울산 1반 김민정·김희윤·박종찬·박진원·이현우가 기존 RAG 주제를 이어 확장했다. 기존 개인 담당, 재사용한 팀 산출물, 이번에 기록으로 확인한 검토 활동을 구분했다.

| 팀원 | 기존 RAG 담당·확인된 활동 | 이번 과제와 연결되는 내용 |
|---|---|---|
| 박종찬 | 스타트업 탐색·기업 정보·자격·자료 준비 담당 | 기존 팀의 후보 15개와 원문 164쪽을 새 조사 계획의 입력으로 사용했다. |
| 김민정 | 기술 분석·기술 근거 담당 | 기존 기술 분석 범위를 기술 성숙도 관점으로 이어 사용하며, 새 Worker가 원문을 다시 조사·검수한다. |
| 김희윤 | 시장·경쟁 분석·고객과 사업 근거 담당 | 기존 시장·고객·사업 분석 범위를 시장성 관점으로 이어 사용했다. |
| 이현우 | 투자 판단·평가표 담당. 임베딩 후보 비교 의견을 공유했다. | BGE-M3 선택을 유지했다. 기존 기업 투자 점수와 이번 보고서의 네 품질 기준은 목적이 달라 구분했다. |
| 박진원 | 보고서 생성·통합 결과 확인·보고서 검토 담당 | 이번 요건과 수업 적용 범위를 제시하고, 제출 문구·보고서·캡처의 겹침·불필요한 화면을 확인해 수정과 최종 검토를 요청했다. |

기존 팀이 찾은 자료원과 시장 분석 코드 제안은 RAG 개발에 반영됐다. 이번 그래프 확장·원문 검수·실행 검증·문서 및 캡처 정리에는 Codex를 활용했다. 위의 기존 담당과 재사용 범위를 이번 신규 코드의 개인별 작성·검수 완료 실적으로 환산하지 않았다. 개인명이 확인되지 않은 팀 제안은 공동 기여로 남겼다.

## 기록과 산출물의 대응

| 근거 | 확인한 범위 |
|---|---|
| 2026-09-29 팀 역할 확정 대화, [기존 README](../../docs/README-rag-original.md#contributors) | 다섯 명의 개인 담당을 확인했다. 담당 배정은 모든 관련 코드를 혼자 작성했다는 증거가 아니다. |
| 2026-09-29 이현우 이름이 붙은 임베딩 후보 비교 공유 기록 | BGE-M3·E5 등 후보 검토 의견을 공유했다. 직접 성능 실험을 수행했다고 확대하지 않았다. |
| 2026-09-30 팀 자료원 전달·시장 분석 코드 제안 기록 | 자료 탐색과 시장 분석의 검색 질문·미확인 처리 개선에 팀 의견이 반영됐다. 작성자를 확정할 수 없는 제안은 개인에게 배정하지 않았다. |
| 이번 과제의 요구사항·문구·캡처 검토 기록 | 박진원이 기존 과제와의 연속성, 샘플 해석, 동일 팀 여부를 확인하고 제출물 수정을 요청했다. 캡처 재촬영과 도구 실행은 Codex 지원 작업이다. |
| `data/prepared/manifest.json`, [app.py](../../app.py), [rag.py](../../rag.py), [prepared_data.py](../../prepared_data.py) | 164쪽·15후보와 기존 검색·자료 검증 코드를 재사용한다. 새 조사는 [orchestration/service.py](../../orchestration/service.py)가 수행하며 과거 `agents/` 함수를 새 Worker로 직접 호출하지 않는다. |

이번 확장의 별도 개인 수행 기록이 확인되지 않은 작업을 새 완료 기여로 만들지 않았다. 미니프로젝트는 설명과 검증 기록의 참고이며, 다른 팀의 보고서나 개인 자료를 이 5인 팀의 공동 성과로 옮기지 않았다.
