# v3 실패 회귀 검증 기록

이 폴더는 **v3 실행에서 품질 검사를 통과하지 못한 과정**을 보존합니다. 최종 보고서가 아니며, 원문 해석 오류가 포함되어 있으므로 **투자 판단에 사용하지 마세요**.

실제 `rewrite → research → fallback` 경로를 확인하기 위한 증거입니다. 보고서를 다시 작성하고 비욘드허니컴의 두 작업만 재조사했으나, 품질 미달 상태에서 수정 한도에 도달해 종료했습니다. 보고서가 세 번 생성됐다는 사실은 품질 개선 성공을 뜻하지 않습니다.

`report-versions.json`에는 LangSmith에서 조회한 보고서 세 판과 평가 세 건이 담깁니다. 실행 화면과 분기 설명은 [추적 안내](../trace-guide.md)를 참고하세요.

최종 제출본은 [과제 평가 보고서](../Agent_evaluation_report.pdf)와 [최종 실행 결과](../final/)입니다. 이 실패 기록과 최종 실행의 수치·판정을 섞어 읽지 않습니다.
