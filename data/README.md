# 후보 목록과 시험용 입력

두 JSON 파일은 연결 확인을 위한 **가상 기업·가상 분석**입니다. 실제 투자 근거로 사용하지 않습니다.
Physical AI 분야는 정했으며, 실제 후보 회사는 팀에서 정하면 됩니다.
대상은 비상장 Seed~Series C 기업으로, Exit를 완료하지 않은 기업입니다.

| 파일 | 쓰는 곳 | 수정 방법 |
| --- | --- | --- |
| `companies.json` | `python main.py`의 전체 후보 목록 | 팀이 선정한 회사를 배열에 순서대로 입력 |
| `test_state.json` | `python main.py --agent 역할`의 기본 입력 | 앞 단계가 준비되지 않았을 때 예제로 사용 |

## 회사 정하기

회사 한 건에는 `id`, `name`, `description`, `website`, `is_example`이 필요합니다.
`id`는 중복되지 않게 짓고, 실제 회사로 바꿀 때는 확인한 이름·소개·홈페이지를 넣습니다.
실제 회사 정보로 바꾸면 해당 회사의 `is_example`을 `false`로 바꿉니다. 앞 단계 분석이 예제이면 전체 결과는 계속 연습용으로 표시됩니다.
사람이 후보를 정해도 됩니다. 자동으로 후보를 찾는 기능은 선택 사항입니다.

```json
[
  {
    "id": "example-robot-a",
    "name": "예제 로봇 회사 A",
    "description": "실제 기업이 아닌 연결 연습용 후보",
    "website": "",
    "is_example": true
  }
]
```

후보 목록을 바꾸어 실행하려면 `python main.py --companies data/my_companies.json`을 사용합니다.
보류된 기업의 분석은 기록에 남고 다음 후보로 넘어갑니다. 모든 후보가 보류되어도 보고서를 만들고 종료합니다.

## 내 역할만 시험하기

`test_state.json`에는 기업 정보·기술·시장·경쟁사·투자 판단과 `history` 예제가 들어 있습니다.
앞 담당자의 코드가 없어도 내 함수에 필요한 입력을 받을 수 있습니다.
다른 테스트는 이 파일을 복사해 필요한 값을 바꾸고 다음처럼 실행합니다.

```bash
python main.py --agent technology --state data/my_test_state.json --output outputs/my-test
```

키와 자료형은 `shared.py`에 맞춥니다. 예제에 대한 `is_example` 표시를 실제 근거에 맞게 유지합니다.
후보만 바꾸면 이전 예제 분석이 그대로 남으므로, 관련 분석 내용·출처도 함께 바꿔 시험하세요.

## 실제 검색 자료를 넣을 때

- 검색용 문서는 **전체 200쪽 이하**이며, 문서 개수는 제한하지 않습니다.
- 각 자료의 제목·원래 주소·해당 페이지를 기록하고 답변에도 실제 사용한 출처를 넘깁니다.
- 게시일을 알면 출처의 선택 항목 `published_at`에 기록합니다. 모르면 `null` 또는 생략합니다.
- 오픈소스 임베딩을 사용하고 선택 이유를 기록합니다. 현재 예제에는 임베딩·모델 다운로드가 없습니다.
- 수업 원본 자료, API 키, `.env`, 공유 권한이 없는 자료를 저장소에 올리지 않습니다.
