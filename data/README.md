# 자료를 두는 곳

- `example.json`: 실제 회사와 관계없는 연습용 입력입니다. 현재 실행은 이 파일을 사용합니다.
- `sources.json`: 앞으로 모을 실제 자료의 제목·URL·페이지 수를 기록합니다.
- 각자의 원본 PDF는 `data/raw/`, 정리한 자료는 `data/processed/`에 둘 수 있습니다. 이 두 폴더의 원문은 GitHub에 올라가지 않습니다.

자료를 모을 때 회사 ID, 제목, 원문 URL, 발행일, 페이지 수를 함께 기록하세요.
RAG에 쓰는 전체 자료는 200쪽 이하입니다. 회사가 바뀌면 자료와 검색 대상도 함께 바꿉니다.
문서 조각에는 출처와 페이지를 남겨서 보고서까지 연결합니다.
공개 웹자료라도 원문 재배포가 가능한지 별도로 확인합니다.
