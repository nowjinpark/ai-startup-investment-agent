# 담당 B: 실제 검색 구현

이 폴더에는 아직 실제 RAG가 구현되어 있지 않습니다.

1. 담당 A가 만든 문서/청크 형식을 공통 계약으로 받습니다.
2. 후보 오픈소스 임베딩을 실제 한국어·영어 자료로 비교합니다.
3. VectorDB와 검색 함수를 구현하고 chunk ID, 원문, URL, 페이지를 함께 반환합니다.
4. 기술 분석 에이전트가 검색 결과를 실제로 사용하게 연결합니다.
5. `data/evaluation/`에 사람이 확인한 질문-정답청크 쌍을 준비하고 Hit Rate@K, MRR을 기록합니다.
6. 검색 근거가 부족하면 추가 검색 또는 확인 불가로 반환합니다. 최대 재시도 횟수를 둡니다.

OpenAIEmbeddings는 과제의 오픈소스 임베딩 조건을 충족하지 않습니다.
리더보드 순위만으로 모델 선택 이유를 대신하지 않습니다.
